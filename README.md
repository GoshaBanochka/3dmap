# Map Marks

Мод-карта для Minecraft 1.21.1 (NeoForge) с общими и личными метками. Сделан для Create SMP сервера
со слабым железом: карту строит и хранит клиент, а сервер только хранит метки и рассылает их игрокам.

## Возможности

**Карта**
- Строится из чанков, которые видел игрок, и сохраняется на диске клиента отдельно для каждого сервера
  и каждого измерения: Верхний мир, Незер, Энд, измерения модов.
- 2D-вид сверху: цвета блоков с оттенками биомов, затенение рельефа, линии высот, прозрачная вода.
  В Незере потолок из бедрока не мешает.
- 3D-вид: вращаемая блочная модель исследованной местности с высотами.
- Оформление в стиле ванильной карты: пергамент, деревянные рамки, ванильные иконки предметов.

**Метки**
- Личные (видит только автор) и общие (видят все игроки).
- У метки есть название, описание, цвет, иконка, координаты, измерение, автор и дата.
- Список меток с поиском и сортировкой по расстоянию, карточка выбранной метки.
- Любую метку можно скрыть со своей карты. Это личная настройка, сервер о ней не знает.
- Создание по правой кнопке мыши на карте, кнопкой «Метка здесь» или командой `/mark`.
- Свои метки меняет и удаляет автор, любые общие метки — оператор.

**Сервер**
- Метки хранятся в данных мира и переживают рестарт.
- Игрок получает только общие метки и свои личные: чужие личные метки на клиент не уходят никогда,
  в том числе операторам.
- Сервер сам проверяет все запросы: длину, лимиты, права, позицию. Частота запросов из интерфейса
  ограничена.
- Мод не делает себя обязательным для игроков: клиент без него не получает пакетов мода, и для него
  просто нет карты и меток. Другие моды сервера (например, Create) могут требовать себя на клиенте
  независимо от этого.

## Установка

Нужны Minecraft 1.21.1, NeoForge 21.1.x и Java 21.

Положите jar в папку `mods` **и на сервере, и у каждого игрока**. Версии мода у сервера и клиентов
должны совпадать: клиент с несовместимой версией зайдёт на сервер как клиент без мода.

Мод работает и в одиночной игре.

## Управление

`M` открывает и закрывает карту. Клавишу можно переназначить в настройках управления,
раздел «Map Marks».

| Действие | 2D | 3D |
|---|---|---|
| Сдвинуть карту | ЛКМ, перетаскивание | ПКМ, перетаскивание |
| Повернуть камеру | — | ЛКМ, перетаскивание |
| Масштаб | колесо, `+` / `-` | колесо, `+` / `-` |
| Выбрать метку | ЛКМ по метке или по строке списка | то же |
| Создать метку | ПКМ по пустому месту | — (только в 2D) |
| Изменить метку | ПКМ по метке | ПКМ по метке |

Клавиши внутри карты:

| Клавиша | Действие |
|---|---|
| `L` | показать или скрыть список меток |
| `N` | метка там, где стоит игрок |
| `Пробел` | вернуться к игроку |
| `V` | переключить 2D / 3D |

## Команды

Названия из нескольких слов и названия на кириллице пишутся в кавычках.

```
/mark add "Главная база" public      создать метку на своей позиции (по умолчанию private)
/mark list                           все видимые вам метки
/mark rename <метка> "Новое имя"
/mark visibility <метка> public|private
/mark describe <метка> <текст>       задать описание (без текста — очистить)
/mark remove <метка>
```

`<метка>` — это название или первые 8 символов id из `/mark list`. Tab подсказывает ваши метки.

## Настройка сервера

Файл `config/threed_map-server.toml` создаётся при первом запуске. Изменения подхватываются без
рестарта и сразу рассылаются игрокам.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `maxMarksPerPlayer` | `50` | сколько меток (общих и личных вместе) может быть у одного игрока |
| `maxNameLength` | `32` | максимальная длина названия, до 64 |
| `maxDescriptionLength` | `256` | максимальная длина описания, до 512; `0` отключает описания |
| `publicMarks` | `"ALL"` | кто может создавать общие метки: `ALL` или `OP_ONLY` |
| `opPermissionLevel` | `2` | уровень прав, который считается оператором |

Если уменьшить лимит меток, существующие метки останутся, но новых игрок создать не сможет, пока
не окажется под лимитом. При `OP_ONLY` уже созданные общие метки остаются общими, и владелец по-прежнему
может их менять.

## Где хранятся данные

| Что | Где |
|---|---|
| Метки (сервер) | `world/data/threed_map_marks.dat` |
| Кэш карты (клиент) | `.minecraft/threed_map/<сервер или мир>/<измерение>/` |
| Скрытые метки (клиент) | `.minecraft/threed_map/<сервер или мир>/hidden_marks.txt` |

Кэш карты можно удалить, если он занимает много места: при следующем входе карта начнёт
заполняться заново.

## Сборка из исходников

```
./gradlew build
```

Готовый jar появится в `build/libs/`.

Для разработки:

| Команда | Что делает |
|---|---|
| `./gradlew runClient` | клиент для разработки |
| `./gradlew runServer` | выделенный сервер для разработки |
| `./gradlew runGameTestServer` | серверные тесты (GameTest), папка `run-gametest/` |
| `./gradlew runAutotestClient` | сценарный тест клиента со скриншотами, папка `run-autotest/` |

Тесты лежат в `src/test` и в jar не попадают. Клиентский тест запускается дважды: первый запуск
создаёт мир и проходит интерфейс, второй перезаходит в мир и проверяет кэш и сохранённые метки.
Итоги пишутся в лог с префиксом `[AUTOTEST]`, скриншоты лежат в `run-autotest/screenshots`.
